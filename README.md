It is a website made with HTML, CSS and JavaScript. This acts as a small portfolio, since it has my previous builds and project designs at Hack Club.

<h3>Running It</h3>
The website is simply deployed on GitHub Pages and can be run using this link: <br>
https://legendplayz83.github.io/potato-portfolio/

On the website, the colour theme is violet and orange, with lots of pumpkins, relating to the Halloween theme :D

<h3>Tech Stack</h3>
-HTML is used to provide the structure and content of the potato-portfolio website. It organises the webpage into sections such as the navigation bar, introduction, skills list, project showcase, and footer. The HTML elements like headings, paragraphs, images, links, and containers are used to present the information for the respective projects and display the projects, including Veekos, Block of Light, StreamForge, ESP-BLJ, and Depth-Rush. The navigation links are included, which can allow the user to see the project on GitHub, where they are open sourced.<br>
<br>
-CSS is used to style the Potato Portfolio website and create a Halloween-inspired appearance. It establishes the dark background, orange accents, purple project cards, and matching text colours. Flexbox is also used here, to arrange the navigation links and skill tags.<br>
<br>
-JavaScript is used to add some dynamic functionality to the potatoo-portfolio website. It holds the GitHub repository link of each project in an object and identifies the project cards on the webpage.<br>
